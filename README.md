# Perioperative Assistant Synthetic Data Generator

Python-based synthetic data generator for the Perioperative Assistant project.

The generator creates simulated perioperative scheduling and operational data for development and testing without using real patient information or protected health information (PHI).

Generated surgical-case data is designed to represent realistic operating-room workflows, including procedure types, services, locations, scheduled case times, actual case times, and case durations.

The synthetic dataset serves as an upstream data source for the Perioperative Assistant application, a .NET and Azure-based project exploring perioperative resource forecasting and operational planning.

The project is structured so that synthetic data can eventually be replaced by an approved healthcare interoperability source, such as HL7 FHIR-derived data, without coupling the forecasting application directly to the synthetic generator.

## Current Development

Current work focuses on:

- Generating realistic synthetic operating-room schedules
- Maintaining a patient-minimal data model
- Simulating scheduled versus actual case timing
- Supporting downstream resource-demand forecasting
- Developing an ingestion architecture that can later support healthcare interoperability

Initial resource forecasting will focus on reusable perioperative equipment, beginning with GlideScope blade availability and reprocessing.

## Data

All data generated by this repository is synthetic and intended for development, testing, and demonstration purposes. No real patient data or PHI is used.
